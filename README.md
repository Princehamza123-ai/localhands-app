# LocalHands

A local artisan and quick-commerce marketplace MVP for Nigeria.

## Features
- Buyer, seller, artisan, and admin flows
- Multi-city support planned for Lagos, Abuja, Port Harcourt, Edo, and Niger State
- Service and product listings
- Local marketplace and category browsing
- Chat and quotes
- Pickup and delivery flows
- Reviews and verification
- Mobile-first design with desktop support

## Stack
- Next.js
- Tailwind CSS
- TypeScript
- Supabase-ready structure

## Getting started

1. Install dependencies:
   npm install
2. Run the app:
   npm run dev
3. Open http://localhost:3000

## Project structure
- `app/` – pages and route handlers
- `components/` – reusable UI
- `lib/` – mock data and utils

## Notes
This is the first MVP version and includes mock content for rapid building. You can later connect the app to Supabase, Stripe, and a real delivery flow.
